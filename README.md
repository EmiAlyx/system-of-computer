一个基于 C++ 语言开发的机房预约系统，主要用于学校机房的预约管理。系统支持学生、教师和管理员三种不同角色的用户登录，每个角色具有不同的操作权限，实现了机房预约、审核、账户管理等功能。
- 实现了用户登录功能，对不同角色的用户进行身份验证和权限管理。
- 完成了学生模块的开发，包括机房预约、查看个人预约、查看所有预约和取消预约等功能。
- 开发了教师模块，实现了查看所有预约和审核预约的功能。
- 完成了管理员模块的开发，包括添加账户、查看账户、查看机房信息和清空预约等功能。
- 对系统进行了测试和调试，修复了发现的问题，确保系统的稳定性和可靠性。


功能：（一）用户登录
实现对学生、教师和管理员的身份验证，根据不同角色赋予相应操作权限，确保系统访问安全。

（二）学生模块
1. **机房预约**：学生可依据自身需求预约机房使用时段。
2. **查看个人预约**：方便学生随时查看自己已预约的机房信息。
3. **查看所有预约**：学生能够了解机房的整体预约情况，合理安排个人时间。
4. **取消预约**：若学生的计划有变，可取消已预约的机房使用。

（三）教师模块
1. **查看所有预约**：教师能查看所有学生的机房预约信息，全面掌握机房使用情况。
2. **审核预约**：对学生的预约申请进行审核，确保预约合理、有序。

（四）管理员模块
1. **添加账户**：为新用户添加账户信息，包括学生、教师账户。
2. **查看账户**：方便管理员管理用户账户，可查看账户详细信息。
3. **查看机房信息**：了解机房的设备状况、可预约时段等信息。
4. **清空预约**：在必要时，管理员可清空所有预约记录，便于重新安排机房使用。
